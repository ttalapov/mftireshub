## 1. Конверсійність — відповіді на ключові питання

### Кнопка дзвінка на кожному екрані скролу

**Sticky-кнопка вже є і працює правильно** — додаткова не потрібна:

| Точка дотику | Рядок | Видимість |
|---|---|---|
| Плаваюча кнопка (FAB) 56×56 px | index.html:787–791 | **завжди на екрані**, лише мобільний (`sm:hidden`) |
| Header «Зателефонувати» | index.html:100 | ≥640px, header фіксований → завжди видно |
| Мобільне меню | index.html:121 | при відкритому бургері |
| Hero, контакти, CTA-банер, футер | 156, 596, 679, 762 | по скролу |

Покриття повне: на мобільному FAB супроводжує весь скрол, на десктопі — фіксований header. FAB 56px ✅ (>44px), з тінню-свіченням, `aria-label` є. Єдиний нюанс — він самотній: туди проситься і месенджер (див. нижче).

### Месенджери — заховані надто глибоко ⚠️

Telegram/Viber/WhatsApp існують **лише в одному місці** — секція контактів (index.html:629–643), це ~75–80% глибини сторінки. У футері — тільки соцмережі-канали (FB/IG/TG-канал/TikTok), не чати.

Для ЦА «водій на стоянці» написати в месенджер часто зручніше за дзвінок (шум, нічна зміна). Зараз цей шлях вимагає проскролити всю сторінку. Рекомендації:
- додати Telegram/Viber поруч із FAB (стек із 2–3 кнопок або розкривний),
- або замінити «Написати на email» у фінальному CTA (index.html:684–688) на месенджери — email для цієї ЦА найслабший канал із можливих.

### Блок розмірів шин (R15–R25) — не перевантажує, але на мобільному читається погано

Рішення з фліп-картками концептуально добре: довідкова інформація схована за кліком і не роздуває сторінку. Проблеми в реалізації:

1. **Тригери «Бренди»/«Розміри» — touch-target ~22–24px** при мінімумі 44px (index.html:215, 275, 347, 407; стилі `.tag`/`.tag-btn` css/main.css:273–284, 465–477: `padding: 0.2rem 0.6rem; font-size: 0.7rem`). Це **єдиний** шлях до асортименту, і в нього важко влучити пальцем. До того ж кнопка візуально майже не відрізняється від сусідніх некликабельних тегів — користувач не здогадається, що це кнопка.
2. **Бренди: 4 колонки шрифтом 0.8rem** (index.html:222) — на екрані 360–390px колонка ≈ 65–70px, а «Bridgestone»/«Continental» в неї не влазять → перенос/тіснота.
3. **Список розмірів довший за картку** → вертикальний скрол усередині фліп-беку зі скролбаром 3px (css/main.css:514–516), який на touch-екрані невидимий — користувач не знає, що нижче є ще R20/R22.5.
4. **Повернення з фліпу не пояснене на мобільному:** підказка лише в `title="Натисніть для повернення"` (index.html:221, 281, 352, 412) — tooltip на touch не існує. Потрібен явний «✕» у куті.

### Лічильники «5000+ шин» — підтверджено критичну проблему 🔴

Статичний HTML (index.html:168, 173, 178):
```html
<span class="stat-number" data-target="5000">0<span class="text-brand-red">+</span></span>
```

Без JavaScript (повільне з'єднання, помилка скрипта, текстовий рендер краулера, режим економії трафіку) сторінка показує:
> **«0+ шин в наявності · 0+ років досвіду · 0+ задоволених клієнтів»**

Це антиреклама рівно в тому місці, де мала бути головна перевага. Фікс простий і не ламає анімацію: у HTML писати фінальні значення (`5000`), а `animations.js` при старті сам скидає в 0 і анімує (count-up уже вміє — досить у `countUp()` починати з 0, що він і робить; треба лише прибрати «0» з розмітки і не чіпати текст до моменту, коли IntersectionObserver спрацював).

## 2. Візуальна консистентність

Загалом дисципліновано: бренд-червоний #c9181e скрізь, два шрифти (Oswald/Nunito) за чіткими ролями, картки 1rem, кнопки full-round. Знайдені розбіжності — у таблицях нижче (Бажано): радіуси іконок 0.75 vs 0.875rem, заголовки карток text-xl vs text-lg, асиметричний ритм секцій `pt-7` (28px) проти `pb-20/28` (80–112px), 33 інлайн-стилі з хардкодом кольорів у фліп-беках.

## 3. Стани hover/focus/active

- **Hover:** опрацьований зразково скрізь (кнопки, картки, навігація, соціконки).
- **Focus:** кастомних стилів **нуль** — лишається тільки браузерний дефолт; на темному фоні в Chrome ледь помітний. Жодного `:focus-visible` у css/main.css.
- **Active / tap-feedback:** жодного `:active`, а Tailwind preflight ще й вимикає `-webkit-tap-highlight-color` (css/main.css:6). Разом це означає: **тап по будь-якій кнопці на мобільному не дає жодної візуальної реакції**. Для `tel:` це маскується відкриттям дзвонилки, але для фліп-тригерів і якірних посилань користувач не розуміє, чи спрацював тап.

## 4. Мобільне меню

- Пункти меню: `padding: 0.75rem 1rem` → ~48px ✅ (css/main.css:81–92).
- Кнопка-бургер: `p-2` + бари 22px → **~38×38px, нижче 44px** (index.html:105). Фікс — `p-3`.
- Закривається по кліку на пункт ✅, `aria-expanded`/`aria-controls` ✅ (js/ui.js:25–44).
- Немає: закриття по Escape/кліку повз, анімації відкриття (з'являється стрибком), блокування скролу під меню. Все — дрібниці (Бажано).

## 5. Анімації

Є і якісні: fade-in-up у hero зі стаггером, scroll-reveal з unobserve, count-up з easing, 3D-фліп, bounce-стрілка, pulse-бейдж. Плавність ок (transform/opacity, без layout-трешінгу).

- 🔴 **`prefers-reduced-motion` не врахований ніде** — 0 збігів у css/main.css, index.html, js/*. Користувачам із вестибулярними розладами програються всі анімації + плавний скрол (`scroll-behavior: smooth`, css/main.css:25). Потрібен один блок:
```css
@media (prefers-reduced-motion: reduce) {
  html { scroll-behavior: auto; }
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
- ✅ Важлива добра деталь: клас `.reveal` додається **через JS** (js/animations.js:15–17), тому без JS контент видимий, нічого не «зависає» прозорим. Правильна архітектура.

## Що зроблено добре (зберегти)

- **FAB дзвінка на мобільному** — 56px, свічення, завжди на екрані. Зразкове рішення під головну конверсію.
- Телефон клікабельний у 7 місцях рівномірно по сторінці.
- Контраст тексту: усі перевірені пари (#888 на #131313 ≈ 5.2:1, #c8c8c8 на #131313 ≈ 10:1) проходять WCAG AA.
- Hero: градієнт `from-black/90` гарантує читабельність H1 поверх фото.
- `.reveal` додається JS-ом → без JS контент не зникає.
- Aria-розмітка краща за середню: `aria-expanded` на бургері та фліп-тригерах, `aria-hidden` на декоративних SVG, `role="banner"/"contentinfo"`.
- Один акцентний колір, двошрифтова система, єдиний стиль карток — впізнаваний вигляд без дизайн-системи.

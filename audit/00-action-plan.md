## Карта залежностей і порядок комітів

```
Пакет 1 (хірургія)     → деплой одразу, нічим не блокується
Пакет 2 (зображення)   → незалежний, деплой другим
Пакет 3 (CSS a11y)     → незалежний; кольори дрібного тексту узгодити з пакетом 4
Пакет 4 (фліп-картки)  → після пакета 3 (використовує новий відтінок червоного)
Пакет 5 (файли)        → незалежний, будь-коли
Пакет 6 (месенджери)   → після відповіді власника
Пакет 7 (поліровка)    → останнім
Tailwind CLI           → за потреби, перед пакетом 4 якщо забракне утиліт
```

## Що потрібно від власника (3 питання)

1. **Точні години відділу продажів** — «щодня» підтверджено; 8:00–20:00 — припущення зі старого JSON-LD. (Графік шиномонтажу Пн–Пт 9:00–18:00 — підтверджено.)
2. **Поштовий індекс** для JSON-LD (припущення: 03061).
3. **Пріоритетний месенджер** для винесення нагору (пакет 6).

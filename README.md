# MF Tires Hub — лендинг

Односторінковий сайт компанії з продажу та ремонту вантажних шин у Києві.
**Прод:** https://mftireshub.pp.ua/

## Як це працює

- **Хостинг:** GitHub Pages з гілки `main`.
- **Деплой:** будь-який пуш у `main` потрапляє на прод за хвилини. Білд-степу немає.
- ⚠️ **Файл `CNAME` не чіпати** — у ньому прив'язка домену mftireshub.pp.ua.

## Структура

```
index.html        — вся сторінка (hero, послуги, переваги, доставка, контакти)
css/main.css      — скомпільований Tailwind 3.4 (purged) + кастомні стилі
js/ui.js          — header, бургер-меню, плавний скрол, активна навігація
js/animations.js  — scroll-reveal, лічильники
js/flip.js        — фліп-картки (бренди, розміри, графік)
img/              — hero, лого (webp + jpg-фолбеки), og-image
404.html          — сторінка помилки GitHub Pages
audit/            — звіти аудитів і план робіт (закрито від індексації в robots.txt)
```

## Важливо знати перед правками

- **Tailwind тут purged-білд без конфігу:** нові утиліти (яких немає в `css/main.css`)
  працювати не будуть. Або додавайте кастомний клас у кінець `main.css`,
  або відновіть білд-ланцюжок (рецепт: `audit/01-structure.md`, розділ С2).
- Контент — лише українською. Головна конверсія — дзвінок (+38 063 171-51-11).
- Лічильники в hero: у HTML стоять фінальні числа, JS сам обнуляє і анімує. Не повертати «0» у розмітку.
- План незакритих робіт: `audit/00-action-plan.md`.
